# AI 提问模板

本文件提供需求分析三步法中需要发给 AI 的完整提问模板。使用时替换其中的需求描述即可。

## 模板一：功能清单生成模板

用于"第二步：功能清单"中，把一段话描述发给 AI 生成结构化功能清单。

```
请根据以下需求描述，帮我生成一份结构化的功能清单，按核心功能和加分功能分类。

需求：[在此粘贴第一步整理好的一段话描述]

要求：
1. 按"核心功能"和"加分功能"两大类列出功能
2. 每个功能需要包含具体实现细节（数据来源、控制逻辑、交互方式、参数设置等）
3. 覆盖数据采集、显示、控制逻辑、本地交互、通信、报警等各个方面
4. 核心功能是系统正常运行必须的功能，加分功能是可以增强体验但非必须的功能
```

**示例（智能温控风扇）**：

```
请根据以下需求描述，帮我生成一份结构化的功能清单，按核心功能和加分功能分类。

需求：设计并实现一个基于STM32智能温控风扇系统。系统能够实时监测环境温度，并根据设定的温度阈值自动调节风扇转速。同时，通过本地按键提供人机交互界面用于参数设置和状态显示，能够通过手机端实时显示采集到的温度等数据，并且能够对系统进行风扇模式切换等远程控制。
```

## 模板二：功能取舍评估模板

用于"第三步：功能取舍"中，让 AI 帮助评估某个功能的取舍建议。可以针对整个清单，也可以针对单个功能。

```
以下是[系统名称]的功能清单。请帮我评估哪些功能应该做、哪些可以舍弃，给出取舍建议。

核心功能：
[列出核心功能]

加分功能：
[列出加分功能]

请针对每个加分功能，使用以下四问法进行评估：
① 这个功能是"核心"还是"加分"？
② 我的时间够不够做？
③ 我的技术能不能做？
④ 去掉这个功能，系统还能不能用？

我的实际情况：[说明自己的技术水平、可用时间、项目要求等]

请给出：每个加分功能的取舍建议（保留/舍弃）及理由。
```

## 提示

- 模板中的需求描述必须来自"第一步"整理好的一段话描述，不要直接用用户原始模糊的说法
- 如果用户能提供更多约束（如：主控型号、传感器型号、屏幕类型、通信方式），在需求描述中补充进去，生成的功能清单会更精准
- AI 生成结果只是候选清单，最终取舍决定权在用户
