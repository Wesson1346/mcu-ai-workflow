# 案例：STM32 智能温控风扇系统（完整三步法示例）

本案例展示需求分析三步法的完整过程，作为执行 skill 时的参考。用户描述新系统时，按此流程推进。

## 第一步：系统描述

**用户原始想法**：我想做一个智能温控风扇。

**整理后的一段话描述**：

> 设计并实现一个基于STM32智能温控风扇系统。系统能够实时监测环境温度，并根据设定的温度阈值自动调节风扇转速。同时，通过本地按键提供人机交互界面用于参数设置和状态显示，能够通过手机端实时显示采集到的温度等数据，并且能够对系统进行风扇模式切换等远程控制。

## 第二步：功能清单

### ① 用户自己先写

```
自己写的功能清单：
1. 温度采集并在OLED上显示
2. 按键可以控制风扇转速
3. 温度升高时风扇自动加速
4. 手机App能查看温度数据
```

### ② AI 生成功能清单

将第一步的一段话描述发给 AI，AI 生成结果如下（按核心功能和加分功能分类）：

```
智能温控风扇系统 — 功能列表（AI生成版）

核心功能
1. 温度采集
- 使用DHT11传感器，实时采集环境温度
- 采集频率：1秒/次

2. 风扇控制
- PWM无级调速，控制风扇转速
- 自动模式：根据温度自动调节转速
- 手动模式：通过电位器手动调节转速

3. OLED显示
- 显示当前温度值
- 显示风扇转速（百分比或档位）
- 显示当前模式（自动/手动）
- 显示温度阈值（初始阈值/上限阈值）

4. 温度自动控制逻辑
- 温度 < 初始阈值 → 风扇关闭
- 初始阈值 ≤ 温度 < 上限阈值 → 按比例调速
- 温度 ≥ 上限阈值 → 风扇全速 + 蜂鸣器报警
- 温度回落至上限阈值以下 → 停止报警

5. 本地按键交互
- 按键1：切换显示界面（主界面/阈值设置界面）
- 按键2：设置界面增加值 / 主界面切换模式
- 按键3：设置界面减少值 / 主界面切换档位

6. WiFi通信
- ESP8266连接WiFi，接入OneNET云平台
- 上传数据：温度、转速、模式、报警状态
- 接收指令：模式切换、阈值设置、风扇开关

7. 手机App控制（UniApp）
- 实时显示温度、转速、模式、报警状态
- 远程切换自动/手动模式
- 远程设置温度阈值（初始阈值/上限阈值）
- 手动模式下远程调节风扇转速
- 设置倒计时关闭（分钟级，可取消）

8. 超温报警
- 温度超过上限阈值 → 蜂鸣器持续鸣叫
- 温度回落至上限阈值以下 → 蜂鸣器停止

加分功能
9. 掉电记忆
- 保存用户设置的阈值和模式，重新上电后恢复

10. 历史数据记录
- 通过OneNET保存温度历史数据
- App端查看历史曲线
```

### ③ 合并调整

将用户自己写的 4 项与 AI 生成的 10 项合并，删掉重复项（如"温度采集并在OLED上显示"拆分为温度采集+OLED显示两项），补充遗漏项，形成完整候选清单。

## 第三步：功能取舍

**用户实际情况**：课设项目，约 2 周时间，学过 STM32 基础，第一次做完整项目。

**评估过程（四问法）**：

| 功能 | 核心/加分 | 时间够吗 | 技术能做吗 | 去掉还能用吗 | 结论 |
| --- | --- | --- | --- | --- | --- |
| 温度采集 | 核心 | - | - | 否 | 保留 |
| 风扇控制 | 核心 | - | - | 否 | 保留 |
| OLED显示 | 核心 | - | - | 否 | 保留 |
| 温度自动控制逻辑 | 核心 | - | - | 否 | 保留 |
| 本地按键交互 | 核心 | - | - | 否 | 保留 |
| WiFi通信 | 核心 | - | - | 否（需远程） | 保留 |
| 手机App控制 | 核心 | 够 | 能 | 否 | 保留 |
| 超温报警 | 核心 | 够 | 能 | 能，但安全重要 | 保留 |
| 掉电记忆 | 加分 | 不够 | 能 | 能 | 舍弃 |
| 历史数据记录 | 加分 | 不够 | 有点难 | 能 | 舍弃 |

**最终确定的功能清单**：

```
1. 数据采集与显示
   - 温度采集：使用DHT11传感器，实时采集环境温度
   - 显示：通过OLED显示屏实时显示当前温度、风扇转速（百分比）、风扇模式（自动/手动）、设定阈值等

2. 小风扇控制逻辑
   - 风扇驱动：通过PWM控制风扇转速，实现无级调速
   - 手动模式：用户通过旋转电位器（模拟输入）调节风扇转速
   - 自动模式：根据环境温度自动调节风扇转速。可设置温度阈值（初始阈值和上限阈值）和档位映射关系

3. 温度自动控制逻辑
   - 当温度低于设定的初始阈值时，风扇关闭
   - 当温度高于等于初始阈值时，风扇开启，且转速随温度升高而增加（例如，每高于阈值1度，增加一个档位）
   - 当温度达到上限阈值时，风扇全速运转，并触发蜂鸣器报警（直到温度低于上限阈值停止报警）

4. 本地按键功能
   - 按键1：切换界面（主界面、温度初始阈值设置、温度上限阈值设置）
   - 按键2：在设置界面增加阈值，在主界面切换风扇模式（自动/手动）
   - 按键3：在设置界面减少阈值，在主界面用于手动模式下切换档位

5. 无线通信与手机APP控制
   - 采用WiFi（ESP8266/ESP32）与手机通信
   - 手机APP功能：
     a. 实时显示当前温度、湿度、风扇转速、模式、报警状态等
     b. 远程切换模式（自动/手动）
     c. 手动模式下，可远程调节风扇转速（百分比）
     d. 设置倒计时：设定时间（分钟），倒计时结束后关闭风扇（可通过APP取消）
     e. 设置温度阈值（初始阈值、上限阈值），并同步到设备
```

**被舍去的功能及理由**：掉电记忆（时间不够）、历史数据记录（时间不够且技术有一定难度），不影响核心功能运行。

## 本章小结

需求分析三步法：一段话描述系统功能 → 功能清单（自己先想+AI生成） → 功能取舍（确定完整功能）

核心原则：
- 先自己思考，再用AI辅助
- 根据自己实际情况，选择相应的功能去做
- 做出来一个能跑的完整系统，比做半个好
