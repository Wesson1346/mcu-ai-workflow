# 常用外设模块卡片参考

写模块卡片时，直接参考以下标准写法，保持字段统一（模块名称/硬件型号/功能描述/验证方法）。接口类型可参考硬件选型清单，这里给出常见写法。

## 传感器类

### DHT11 温湿度传感器（单总线）

```
模块：温度采集
├─ 硬件型号：DHT11（单总线）
├─ 功能描述：每隔1秒读取环境温度；输出温度值，供 OLED 显示、主控逻辑判断和云平台上传使用
└─ 验证方法：串口打印温度，用手捏传感器看数值明显变化
```

### 光敏电阻/光敏模块（ADC）

```
模块：环境光照采集
├─ 硬件型号：光敏电阻/模块（ADC）
├─ 功能描述：每隔1秒通过 ADC 采集环境光照，转成光照值（0~100，越大越亮）；作为自动调光依据，供 OLED 显示、主控逻辑和云平台上传使用
└─ 验证方法：串口打印光照值，用手遮挡光敏传感器数值明显变小，移开后恢复
```

### HC-SR501 人体红外感应（GPIO）

```
模块：人体感应
├─ 硬件型号：HC-SR501 人体红外模块（GPIO）
├─ 功能描述：检测是否有人（人靠近输出高电平）；输出人体状态，供主控逻辑判断开关灯、OLED 显示状态
└─ 验证方法：人走近时串口打印"有人"，走开后打印"无人"，观察电平跳变
```

## 显示类

### 0.96寸 OLED SSD1306（I2C）

```
模块：OLED显示
├─ 硬件型号：0.96寸 SSD1306（I2C）
├─ 功能描述：显示系统状态数据（温度/亮度/转速/模式/阈值等）；读取各模块数据并刷新显示，作为本地人机交互输出界面
└─ 验证方法：先显示固定文字确认正常，再确认数据能实时变化
```

## 执行器类

### 风扇（两种形态按硬件选型清单为准）

**形态A：裸 5V 直流风扇 + S8050 三极管驱动（PWM）**

```
模块：风扇PWM控制
├─ 硬件型号：5V直流风扇 + S8050三极管驱动（PWM）
├─ 功能描述：接收占空比（0~100%）控制风扇转速；自动模式由主控按温度给占空比，手动模式由电位器给定
└─ 验证方法：设50%占空比，看风扇是否转；改变占空比看转速变化
```

**形态B：自带驱动的风扇模块（PWM，模块化直驱）**

```
模块：风扇PWM控制
├─ 硬件型号：自带驱动的风扇模块（PWM）
├─ 功能描述：接收占空比（0~100%）控制风扇转速；自动模式由主控按温度给占空比，手动模式由电位器给定
└─ 验证方法：设50%占空比，看风扇是否转；改变占空比看转速变化
```

### LED 灯条/高亮 LED（PWM）

```
模块：LED调光控制
├─ 硬件型号：高亮 LED 灯条/模块（PWM）
├─ 功能描述：接收占空比（0~100%）控制亮度，实现无级调光；自动模式由光照自动调节，手动模式由按键/App调节
└─ 验证方法：设50%占空比观察亮度；改变占空比亮度随之变化
```

## 交互类

### 6×6 轻触按键 ×N（GPIO）

```
模块：按键输入
├─ 硬件型号：6×6 轻触按键 ×N（GPIO）
├─ 功能描述：检测各按键的按下事件，带软件防抖（约20ms）；按键结果作为主控逻辑的用户指令（切模式/调阈值/开关）
└─ 验证方法：按按键，串口打印对应的按键编号
```

### 10K 旋转电位器（ADC）

```
模块：电位器输入
├─ 硬件型号：10K旋转电位器（ADC）
├─ 功能描述：读取电位器旋钮位置并转成数值（0~4095/0~100）；手动模式下作为转速/亮度的给定值
└─ 验证方法：旋转电位器，串口打印数值随之变化
```

## 报警类

### 有源蜂鸣器（GPIO）

```
模块：蜂鸣器报警
├─ 硬件型号：有源蜂鸣器（GPIO）
├─ 功能描述：满足报警条件（如超温/超限）时发声；由主控逻辑判断触发，输出电平控制响/停
└─ 验证方法：GPIO拉高，蜂鸣器响；拉低，蜂鸣器停
```

## 通信类

### ESP8266 ESP-01S WiFi 模块（USART）

```
模块：WiFi通信
├─ 硬件型号：ESP8266 ESP-01S（USART）
├─ 功能描述：连接 WiFi 接入云平台（SSID/密码用变量配置）；上传数据（状态/传感器值），接收 App 下发的指令并执行
└─ 验证方法：串口打印 "WiFi Connected"；云平台能看到设备上线和数据更新
```

## 编写要点

- **接口**写在型号后面的括号里（单总线/I2C/PWM/GPIO/ADC/USART），与硬件选型清单一致
- **功能描述**尽量包含：采集/控制细节、输入→输出、触发条件、数据给谁用
- **验证方法**尽量可观察：手捏/遮挡/按键/设占空比等能直接看到的现象
- **执行器形态**（裸器件+驱动 vs 模块化直驱）以硬件选型清单的选型结果为准，不擅自改
