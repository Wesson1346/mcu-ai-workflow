本次搭建方式：**PCB 板（模块化直插底板）**——PCB 作为布线底板，功能模块经排母/排针直插，走线替代杜邦线；主控用最小系统板插入底板，整板由核心板 USB 口供电，PCB 上不画电源/驱动电路。

## 三、选型说明

- **PCB 底板作用**：PCB 仅承担"布线 + 承载"作用，模块经排母/排针直插，PCB 铜走线替代面包板阶段的杜邦线，不额外设计电源/驱动电路。
- **供电方式**：整板由核心板 USB 口供电。核心板 5V 引脚给 5V 模块（如 5V 风扇模块）；3.3V 引脚给 OLED/DHT11/蜂鸣器/ESP8266 等 3.3V 模块。
- **模块直插提示**：直插前确认模块排针顺序与 PCB 排母丝印一致（VCC/GND 对齐），避免插反损坏。
- **ESP8266 注意**：ESP-01S 若直插排母，其 CH_PD(EN) 脚需 10kΩ 上拉到 3.3V 才能工作；若 ESP 联网电流导致供电不稳，可增加一片 AMS1117-3.3 单独供电（见载板物料"可选电源件"）。
- **其它方案说明**：若需要自绘驱动电路（学驱动原理）或裸片最小系统、板载电源等更深度的 PCB 设计，需另行设计相关电路，本清单默认不包含。
- **执行器等价方案（如适用）**：方案A「裸器件+驱动电路」需自行设计驱动与续流等；方案B「模块化直驱」集成驱动、接线简单。本清单采用方案B。

## 四、选型核对

- [ ] 功能清单里的每一项功能都有对应硬件，无遗漏
- [ ] 搭建方式为 PCB（模块化直插底板），清单未混入面包板/杜邦线等面包板内容
- [ ] 加分功能与舍去功能已核对，舍去的不需要硬件
- [ ] 执行器有等价方案时已选更模块化方案，不双方案并列
- [ ] 供电方式已明确（核心板 USB 供电），供电电压匹配（STM32 3.3V 逻辑）
- [ ] 只做了型号/接口选择，未分配引脚
