# PCB 模块化直插底板 — 载板物料参考

本文件用于"PCB 板搭建"分支（模块化直插底板方案）的载板物料选型参考。该方案下 PCB 只作为**布线底板**：面包板上的模块原样经排母/排针直插，PCB 铜走线替代杜邦线，主控用最小系统板插在底板上，整板由核心板 USB 口供电，PCB 上不画电源/驱动电路。

仅补充"功能→模块映射"之外的**板级物料**。功能模块本身（传感器/OLED/ESP8266/蜂鸣器等）仍从 `common-modules.md` 选用，型号接口不变。

## 一、接口类（核心，几乎必有）

| 类别 | 物料 | 型号/规格 | 说明 |
| --- | --- | --- | --- |
| 主控底座 | 双排排母 | 2×20P（或按核心板实际排针数） | 核心板排针插入用 |
| 模块底座 | 2.54mm 单排排母 | 2P / 3P / 4P 等 | OLED(4P)、DHT11(3P)、蜂鸣器(2P) 等 |
| ESP8266 底座 | 2×4P 排母 或 ESP-01S 适配器底座 | 2×4P 2.54mm | ESP-01S 直插用；适配器底座自带 CH_PD 上拉，更省事 |
| 风扇接线 | 接线端子 | KF301-2P / 3P | 风扇模块引线（或功率线）接板 |
| 排针 | 2.54mm 排针 | 单排 / 双排 | 焊接固定与引出 |

## 二、直插小件（直接焊在 PCB 上，无需模块）

| 类别 | 物料 | 型号/规格 | 说明 |
| --- | --- | --- | --- |
| 电位器 | 旋转电位器 | 10K（直插三脚） | 手动调速输入，中间抽头接 ADC |
| 按键 | 轻触按键 | 6×6 轻触（四脚直插） | 本地交互，软件消抖即可 |
| 蜂鸣器（若用器件） | 有源蜂鸣器 | 3.3V/5V 有源 | 模块化方案则直接插模块，不需要此件 |

## 三、电源与阻容（可选，默认不需要）

> 默认方案：整板由**核心板 USB 口供电**，PCB 上不画任何电源电路。以下物料仅在实际供电不稳或用户主动要求时才添加。

| 类别 | 物料 | 型号/规格 | 说明 |
| --- | --- | --- | --- |
| 稳压（按需） | LDO | AMS1117-3.3 | ESP8266 联网瞬间电流大，若实测电压跌落导致 WiFi 复位，加一片单独喂 ESP |
| 滤波 | 电解电容 | 100uF / 220uF | ESP 供电脚旁并电容 |
| 去耦 | 瓷片电容 | 100nF | 电源入口、关键芯片旁 |
| 上拉 | 电阻 | 4.7kΩ / 10kΩ | ESP-01S 的 CH_PD(EN) 需 10kΩ 上拉（用适配器底座则免）；DHT11 数据线 4.7kΩ（用模块则板上已带） |
| 限流 | 电阻 | 1kΩ | LED、蜂鸣器等串联限流 |
| 指示 | LED | 发光二极管 | 电源/状态指示 |
| 输入（按需） | USB/DC 座、自锁开关 | Micro-USB 或 DC-005 | 仅当不用核心板 USB 供电时才需要 |

## 四、下载调试与结构件（可选）

| 类别 | 物料 | 型号/规格 | 说明 |
| --- | --- | --- | --- |
| 调试口 | 排针 | SWD 4P（3V3/SWDIO/SWCLK/GND） | 预留 ST-Link 下载口（核心板自带排针时可省略） |
| 固定 | 铜柱/螺母 | M3 | 固定 PCB 与模块 |
| 结构 | 螺丝孔 | 直径 3mm | PCB 上预留，含在板框设计内 |

## 使用提示

- **PCB 只是布线板**：模块型号与面包板方案完全一致，PCB 载板仅需"接口类 + 直插小件"，绝大多数情况下不需要第三、四节内容
- **供电默认**：核心板 USB → 板上 5V/3V3 脚做总线走线；风扇等 5V 模块接核心板 5V，其余 3.3V 模块接 3V3
- **ESP-01S 注意**：直插排母时其 CH_PD(EN) 引脚需 10kΩ 上拉到 3.3V，否则不工作；用 ESP-01S 适配器底座可免去
- **布线提示**：功率线（风扇/蜂鸣器）走线远离 DHT11 单总线与 ADC 抽头走线，电源走线加粗
- **不分配引脚**：模块信号线接到核心板哪个引脚属于"系统电路搭建"阶段，不在本参考中决定
