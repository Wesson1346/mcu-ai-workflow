# 案例：STM32 智能温控风扇系统（完整四步法示例）

本案例展示"功能→硬件映射法"的完整过程，作为执行 skill 时的参考。用户提供新系统功能清单时，按此流程推进。

## 第一步：解析功能清单

**输入**：智能温控风扇系统需求功能清单（来自 mcu-requirement-analysis 产出的 md 文档）

**提取的功能与硬件方向映射草表**：

| 功能 | 功能要素 | 硬件方向 |
| --- | --- | --- |
| ① 温湿度采集 | 数据采集 | 温湿度传感器 |
| ② OLED 显示 | 显示输出 | 显示屏 |
| ③ 风扇自动调速 | 执行器控制 | 风扇+驱动 |
| ④ 本地按键交互 | 本地交互 | 按键 |
| ⑤ 温度阈值设置 | （复用按键+OLED） | 无需额外硬件 |
| ⑥ 超温报警 | 报警提示 | 蜂鸣器 |
| ⑦ 手动调速 | 本地交互/输入 | 电位器 |
| ⑧ WiFi 通信 | 通信 | WiFi 模块 |
| ⑨ 手机 App 远程控制 | （软件，复用WiFi） | 无需额外硬件 |

**确认搭建方式**：本案例经询问确认搭建方式为**面包板搭建**，故按面包板分支输出模块化清单（含面包板套装），不混入 PCB 相关内容。

## 第二步：功能 → 硬件映射

对照 `references/common-modules.md` 选型库，逐项映射：

| 功能 | 硬件 | 型号 | 接口 |
| --- | --- | --- | --- |
| ① 温湿度采集 | 温湿度传感器 | DHT11 | 单总线 |
| ② OLED 显示 | OLED 显示屏 | 0.96寸 SSD1306 | I2C |
| ③ 风扇自动调速 | 自带驱动的风扇模块 | 风扇模块 | PWM |
| ④ 本地按键交互 | 轻触按键 | 6×6轻触按键 ×3 | GPIO |
| ⑤ 温度阈值设置 | （复用按键+OLED，无额外硬件） | — | — |
| ⑥ 超温报警 | 有源蜂鸣器 | 有源蜂鸣器 | GPIO |
| ⑦ 手动调速 | 旋转电位器 | 10K电位器 | ADC |
| ⑧ WiFi 通信 | WiFi 模块 | ESP8266 ESP-01S | USART |
| ⑨ 手机 App 远程控制 | （软件，复用 ESP8266） | — | — |

**映射技巧说明**：
- ⑤ 阈值设置复用按键和 OLED，不增加硬件
- ⑨ App 远程控制复用 ESP8266，只写软件
- ③ **风扇存在"裸 5V 风扇 + S8050 三极管驱动"与"自带驱动的风扇模块"两种等价方案，遵循"有等价方案优先选更模块化"，选用方案B 模块化风扇**（自带驱动，直连 GPIO/PWM，省去驱动电路）；两种方案差异仅在"选型说明"章节客观陈述，不写倾向性选型建议

## 第三步：选型补充与校对

**补齐必备项**：
- 主控芯片：STM32F103C8T6 最小系统板
- 电源/接线：面包板、杜邦线、电源适配器
- 驱动电路：风扇选**方案B 模块化风扇**（自带驱动），**无需额外驱动电路**；主控、电源均合并进完整清单

**完整清单（含主控和电源，不含参考价）**：

| 功能 | 硬件 | 型号 | 接口 |
| --- | --- | --- | --- |
| 主控 | 单片机 | STM32F103C8T6 最小系统板 | — |
| 程序下载 | USB-TTL 下载器 | CH340 USB-TTL 模块 | USART |
| ① 温度采集 | 温湿度传感器 | DHT11 | 单总线 |
| ② 显示 | OLED 显示屏 | 0.96寸 SSD1306 | I2C |
| ③ 风扇调速 | 自带驱动的风扇模块 | 风扇模块 | PWM |
| ④ 按键 | 轻触按键 | 6×6轻触按键 ×3 | GPIO |
| ⑥ 报警 | 有源蜂鸣器 | 有源蜂鸣器 | GPIO |
| ⑦ 手动调速 | 旋转电位器 | 10K电位器 | ADC |
| ⑧ WiFi | WiFi 模块 | ESP8266 ESP-01S | USART |
| 电源 | 面包板/杜邦线 | 面包板套装 | — |

**校对**：
- ✅ 9 项核心功能全部对应到硬件，无遗漏
- ✅ 加分功能全舍弃，无额外硬件
- ✅ 风扇有等价方案时优先选更模块化方案（方案B 模块化风扇），不双方案并列
- ✅ 供电匹配：风扇模块按模块供电要求接线；其余均 3.3V；ESP8266 必须 3.3V
- ✅ 只做型号选择，未分配引脚

## 第四步：输出 md 文档

基于 `assets/hardware-list-template.md` 模板，生成 `智能温控风扇系统硬件选型清单.md`，保存到当前工作目录，内容包含：选型依据、核心硬件清单（含主控/电源）、选型说明、选型核对。

## 本章小结

功能→硬件映射法：解析功能清单 → 确认搭建方式（面包板/PCB） → 功能映射硬件（按搭建方式分支） → 选型补充校对 → 输出 md 文档。

核心原则：
- 够用就行，不追求高端
- 资料多的优先、接口通用的优先
- 只选型号，不分配引脚（留给系统电路搭建）
