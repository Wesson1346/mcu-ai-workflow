## 三、搭建总思路

```
① 电源先行：先接好 3.3V 和 GND 电源轨，用万用表确认电压
② 单片机就位：STM32 最小系统板插面包板中间
③ 逐个加模块：接一个、测一个、不要积压
```

**接线原则**：先断电、再接线；先电源、再信号；先固定、再插拔。

**杜邦线颜色**：红线 VCC、黑线 GND、黄/绿/蓝/白 信号线。

## 八、接线注意事项

```
① 供电电压：STM32 是 3.3V 逻辑，各模块供电按要求（ESP8266 必须 3.3V）
② 每次只接一个模块验证，接一个测一个
③ 不要带电拔插
④ 信号线尽量短（< 20cm）
⑤ 所有 GND 必须共地（90% 读不到数据是 GND 没接好）
⑥ 电源噪声提醒：若用面包板搭建电路，且由电脑 USB 口给单片机供电，尽量不使用外接 HDMI 显示器（尤其是笔记本电脑）——某些情况下外接显示器会带来电源噪声，干扰单片机正常工作
```
