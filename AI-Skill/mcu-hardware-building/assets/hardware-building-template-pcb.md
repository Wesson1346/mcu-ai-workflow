## 三、搭建总思路

```
① 先焊后插：先把底板上的排母、端子、排针焊完，再插模块
② 先电源后信号：先焊电源输入与供电网络，测通断与电压，再处理信号排母
③ 先低后高：按元件高度从低到高焊，避免高元件挡住烙铁
④ 焊一类验一类：每焊完一类元件立刻测通断，不要全部焊完再查
⑤ 最后插模块：底板确认无短路后再插主控与各模块，插一个验一个
```

**焊接原则**：先断电、再焊接；先无源（排母/端子/排针）、后有源（模块）；每个焊点 2~3 秒，避免烫坏焊盘。

**走线约定**：底板 3.3V 与 GND 用独立铜箔网络；模拟信号（ADC）走线远离 PWM/时钟线；信号线尽量短且不跨分割。

## 八、接线注意事项

```
① 供电电压：STM32 是 3.3V 逻辑，各模块供电按要求（ESP8266 必须 3.3V 且需足够电流）
② 上电前必测：用万用表通断档确认 3.3V 与 GND 无短路，确认无虚焊
③ 排母方向：所有排母缺口方向统一，避免模块插反烧毁
④ ESP-01S 的 CH_PD 需 10k 上拉到 3.3V，否则模块不启动
⑤ 所有 GND 必须共地（90% 读不到数据是 GND 没接好）
⑥ 焊接顺序：先矮后高、先无源后有源；模块最后插
⑦ 电源余量：若底板同时给 ESP8266 与 OLED 供电，建议 5V 输入端电流 ≥1A
⑧ 结构检查：铜柱高度需保证模块插上后不与底板元件干涉
```
